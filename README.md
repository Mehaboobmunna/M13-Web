# BuildSmith

A precision engineering and digital workshop suite built with React & TypeScript. Features jobsite-grade Construction Master Pro & Imperial dimensional calculators (with fractional tape history down to 1/128"), productivity tools, real-time card showdown games, interactive wallpaper galleries, and engineering blog posts.

## Features

### 🎮 Games
- **Quartet Clash (v3.2)**: 4-player fast-passing card showdown against 3 smart AI bots with clockwise simultaneous passing, 16 themed decks (Animals, Superheroes, Ocean, Planets, Video Games, etc.), card vault, sound effects, and confetti celebrations.
- **Crown & Conclave - Find the Thief (v1.6)**: Medieval social deduction mini-game featuring the royal court hierarchy (King, Queen, Bishop, Knight, Pawn, and Thief). Players assume identities, uncover clues, level accusations, and score prestige.

### ⚡ Web Apps
- **Pulse**: Minimalist multi-project time tracker with start/stop intervals, active timer banner, project/task CRUD, duration adjustment modal with quick deductions, CSV export, and JSON backup/restore.
- **File Name Grabber**: Drag-and-drop file processing tool that extracts, cleans, sorts, and copies file lists with optional extension toggling.
- **Drawing Series Builder**: Specialized engineering drawing tool that detects sequential numbering, expands ranges, handles sub-sheets, and collapses 3+ consecutive numbers into clean hyphenated series.
- **Imperial Calculator**: Architectural dimensional calculator supporting feet, inches, fractions (down to 1/16"), arithmetic operations (`+`, `-`, `*`, `÷`), scalar operations, and calculation history.

### 🖼️ Wallpapers
- Curated gallery across 10 categories (Minimal, Nature, Cyberpunk, Space, Abstract, Vehicles, Entertainment, Anime, Architecture, Dark/OLED).
- Device filters (Desktop 16:9, Mobile 9:16, Ultrawide 21:9), search, color palette swatches, 4K resolution specs, favorites, and high-res downloads.

### 📝 Engineering Blog
- Architectural breakdowns of the real-time card passing algorithms, drawing series parser regex, and time tracking workflow.

## Technology Stack
- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Audio & FX**: Web Audio API Synthesizer & Canvas Confetti
